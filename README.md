# 🚀 Habit Flow

A full-stack Habit Tracking Application built using React.js, Node.js, Express.js, and MySQL to help users manage daily habits, track progress, and improve productivity.

---

## ✨ Features

✅ User Authentication with JWT  
✅ Protected Routes  
✅ Create, Read, Update, Delete (CRUD) Operations  
✅ Daily Habit Tracking  
✅ Responsive User Interface  
✅ REST API Integration  
✅ MySQL Database Connectivity  

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Authentication
- JWT (JSON Web Token)
